# AutoMPlusFinder 1.1.1

WoW Retail 12.1.0 (Interface 120100)용 쐐기 파티 감시 애드온입니다.

## 사용법

1. 기존 AutoMPlusFinder 폴더를 백업한 뒤 이 ZIP 안의 AutoMPlusFinder 폴더를 `_retail_/Interface/AddOns/`에 설치합니다. 게임을 재시작하세요.
2. `/ampf`를 입력하고 던전, 최소/최대 단수, 역할을 선택합니다.
3. **감시 시작**을 한 번 누릅니다.
4. 창을 닫고 퀘스트/채집을 계속합니다. 기본 30초 간격이 지난 뒤 다음 실제 키 입력 또는 월드 마우스 클릭에서 검색합니다.
5. 조건에 맞는 파티를 발견하면 소리와 화면 메시지로 알립니다. `/ampf`로 결과를 열어 **신청**을 직접 클릭합니다.
6. 감시 중지 버튼 또는 `/ampf stop`으로 끕니다.

## 감시 동작과 제한

- UI 창을 닫아도 감시가 유지됩니다. 재접속 또는 `/reload` 후에는 감시 시작을 다시 눌러야 합니다.
- 타이머는 대기 시간과 응답 지연만 확인합니다. 타이머에서 검색하거나 입력을 합성하지 않습니다.
- 키 입력은 원래 게임 동작으로 그대로 전달됩니다. 마우스를 가로채는 화면 덮개를 사용하지 않습니다.
- 전투, 사망, 파티 참가, 내 파티 모집, 파티 찾기 창 사용, 문자 입력 중에는 검색을 쉽니다.
- 다른 애드온이나 기본 파티 찾기에서 검색을 실행하면 감시가 중지됩니다. 다른 검색 결과를 잘못 알리지 않기 위한 동작입니다.
- 감시 시작 후 첫 검색에서 기본 파티 찾기의 검색 문자열을 비웁니다. 필터 조건은 AutoMPlusFinder 창에서 지정합니다.
- 실패하거나 20초 동안 응답이 없으면 재시도 대기를 설정 간격의 2배부터 최대 300초까지 늘립니다. (기본 30초 설정에서는 60초, 120초, 240초, 300초) 성공하면 기본 간격으로 복귀합니다.
- 중지/시작을 반복해도 기존 대기 시간을 건너뛰지 않습니다.
- 30초는 애드온의 보수적인 기본값이며 Blizzard가 보장하는 허용량이 아닙니다. 서버 검색 제한을 완전히 방지한다고 보장하지 않습니다.
- 처음 발견한 조건 일치 파티를 알립니다. 같은 검색 결과 ID는 마지막 발견 후 30분간 기억하므로 잠시 목록에서 사라졌다 다시 나타나도 중복 알리지 않습니다. 새 공고 ID로 재등록되면 새 파티로 취급될 수 있습니다.
- 게임을 내려두거나 아무 입력도 하지 않으면 새 검색이 실행되지 않습니다. 신청은 항상 직접 클릭해야 합니다.

## 명령어

- `/ampf`: 창 열기/닫기
- `/ampf show`, `/ampf hide`: 창 표시/숨김
- `/ampf watch` 또는 `/ampf on`: 감시 켜기 (다음 실제 입력에서 검색)
- `/ampf stop` 또는 `/ampf off`: 감시 끄기
- `/ampf reset`: 감시 중지 및 필터 초기화
- `/ampf help`: 도움말

## 검증

Lua 5.1 환경에서 전체 파일 로딩, 감시 스케줄러, 실제 입력 콜백 연결을 모의 시험했습니다. 검색 간격, 중복 호출 방지, 전투/파티/문자 입력/파티 찾기 화면에서의 일시정지, 오류와 응답 지연의 대기 증가, 중복 알림 방지, 다른 검색과의 충돌 처리를 확인했습니다.

실제 WoW 12.1.0 클라이언트에서의 API 허용 여부와 퀘스트/채집 중 동작은 아직 검증하지 않았습니다. 보호 함수 오류나 Lua 오류가 뜨면 감시를 중지하고 오류 내용을 알려주세요.

## 1.1.1 검색 간격 설정

창의 검색 간격(초) 입력란에 10~300 사이 숫자를 입력하고 Enter를 누르거나 다른 곳을 클릭하면 저장됩니다. /ampf interval 15 명령으로도 설정할 수 있습니다. 기본값은 30초입니다. 진행 중인 검색 대기나 실패 후 지연은 단축하지 않고 유지합니다. 이후 검색은 변경한 간격을 사용합니다. 10초는 애드온이 허용하는 설정 하한이며 서버가 보장하는 안전 간격이 아닙니다. 실패 시 대기는 설정 간격의 2배부터 최대 300초까지 늘어납니다.
